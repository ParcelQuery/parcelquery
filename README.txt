ParcelQuery V3

Includes public tracking, status timeline, progress bar, package information, history, support section, responsive design, admin dashboard, shipment creation/update/deletion and statistics.

Demo admin: username admin / password parcel-demo

IMPORTANT: This is a front-end demonstration. Credentials and shipment records use browser localStorage and are not secure for production. A real multi-user deployment should use secure authentication and a backend database.

GitHub Pages: create a public repo named parcelquery, upload index.html/style.css/script.js, then Settings > Pages > Deploy from branch > main > root.

ParcelQuery is a shipment tracking and logistics website.
